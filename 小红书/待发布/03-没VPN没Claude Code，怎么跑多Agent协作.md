很多人问我：没VPN、配置低，怎么玩多Agent？

我家三台旧笔记本，跑不动Claude Code，也用不了海外API。用Qwen CLI + GLM Coding Plan搭了一套OpenClaw协作系统，18天跑了20个项目。

今天不吹结果，聊点真正有用的坑。

⚠️ 我踩过的4个坑

坑1：Agent之间上下文不共享
→ 三台电脑各自为政，孔明不知道凤雏在干嘛
→ 解决：GitHub仓库当"共享记忆"，做任何事前先pull，做完立刻push

坑2：任务冲突
→ 凤雏和孔明同时改一个文件，冲突了
→ 解决：严格按SOUL.md分工，用Issue认领机制，冲突时孔明（Mac）裁决

坑3：知识不沉淀
→ 之前踩过的坑，下次还会踩
→ 解决：建knowledge-base目录，每个项目做完提取关键经验。现在18天积累了35次反思报告

坑4：没有监控=失控
→ 有段时间三虾在空转，我没发现
→ 解决：health-check.sh检查系统状态，凤雏每天16:43签到汇报

✅ 这套系统适合谁

适合：有多台旧设备、做并行项目、愿意花10分钟写SOUL.md
不适合：想一键开箱即用

哈哈，管理AI和管理人逻辑一样——分工、协作、沉淀、把关。
