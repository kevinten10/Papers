# 🎯 让三虾AI当评审员，70%的想法直接淘汰

我砍掉一个想法，比做出它更有价值。

三台旧电脑跑OpenClaw，用Qwen CLI连上GLM Coding Plan。我让「孔明」「卧龙」「凤雏」当评审员，从awesome-ai-ideas库拉取创意，五维打分。

## ❌ 被AI淘汰的想法

- "AI天气穿搭推荐" → 差异化太低
- "AI读书笔记生成器" → Readwise、Notion AI已成熟
- "AI宠物健康管家" → 涉及医疗合规，可行性存疑

这些想法乍一听都"还行"，但过一遍框架，问题全暴露。

## 🔄 五维评估框架

1. **价值** — 用户真的痛吗？
2. **可行性** — 一个人能实现吗？
3. **差异化** — 你的角度是什么？
4. **时机** — 太早还是太晚？
5. **影响** — 能影响多少人？

**总分≥7分才进队列。** 500+创意评估下来，70%+淘汰率。

独立开发者最稀缺的不是能力，是方向判断。
