## 🎯 使用指南

### 商业人脉对接
1. **首次使用**: 先阅读《校友对接行动计划.md》了解完整策略
2. **日常跟踪**: 使用《校友对接跟踪表.md》记录进展
3. **定期更新**: 每周更新一次跟踪表，总结经验教训
4. **成果评估**: 通过资源统计评估对接效果

### 职场社交经验
1. **新入职场**: 先阅读《职场社交经验汇总.md》快速入门
2. **重点学习**: 根据需求选择专项指南（前领导关系、沟通协作等）
3. **实践应用**: 从简单社交开始，逐步积累经验
4. **定期复习**: 每季度回顾一次，巩固学习成果

## 💡 实用建议

- **主动出击**: 不要被动等待，主动联系校友
- **精准表达**: 明确说明需求和目的
- **礼貌跟进**: 及时反馈和感谢
- **资源互换**: 考虑如何为对方创造价值
