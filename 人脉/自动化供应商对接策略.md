## 📞 接触策略与执行计划

### 第一阶段：信息收集（第1周）
**目标**：建立目标企业与潜在校友的映射关系

#### 具体行动：
1. **LinkedIn深度搜索**
   - 每天搜索2-3家目标企业
   - 记录所有江南大学校友信息
   - 分析职位层级和联系方式

2. **企查查信息核实**
   - 查询企业高管背景
   - 确认教育经历
   - 获取联系方式

3. **校友会资源动员**
   - 联系江南大学校友会
   - 咨询自动化行业校友资源
   - 获取校友通讯录

### 第二阶段：初步接触（第2周）
**目标**：建立与关键校友的联系

#### 接触优先级：
1. **高层校友**：总经理、技术总监
2. **中层校友**：部门经理、项目总监
3. **业务校友**：销售总监、客户经理

#### 接触话术模板：
```
[校友姓名]您好：

我是江南大学[专业][届别]毕业生[您的姓名]。

在[LinkedIn/校友录]看到您在[公司名称]担任[职位]，我一直关注贵公司在自动化领域的出色表现。

我的朋友[朋友姓名]正在[行业]创业，准备考察无锡的自动化供应商。

作为校友，希望能向您请教行业发展趋势，并了解贵公司的产品和服务。

如果方便的话，能否安排一次简短交流？

期待您的指导！
联系方式: [电话/微信]
```

### 第三阶段：深度对接（第3-4周）
**目标**：实现考察安排和合作对接

#### 跟进策略：
1. **24小时内首次跟进**
2. **3天内发送详细需求**
3. **1周内确认考察计划**
4. **持续维护关系**

#### 考察准备清单：
- [ ] 企业基本情况介绍
- [ ] 具体考察需求说明
- [ ] 人员安排和时间规划
- [ ] 商务合作意向表达

## ⚠️ 风险控制

### 可能挑战：
1. **校友分布不均**：部分企业可能没有江南大学校友
2. **职位层级限制**：普通员工无法安排高层接触
3. **竞争敏感性**：供应商可能不愿接待竞争对手

### 应对策略：
1. **多元化渠道**：不依赖单一校友资源
2. **价值交换**：提供对等价值（如技术咨询、行业资讯）
3. **专业态度**：展现专业性和合作诚意
