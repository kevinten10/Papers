# 高层联系指南

## 🎯 核心原则

### 为什么必须联系高层？
1. **决策效率**: 高层拥有最终决策权，避免层层审批
2. **资源配置**: 能调动企业核心资源进行深度考察
3. **战略价值**: 高层更了解企业发展方向和合作机会
4. **人脉质量**: 高质量人脉带来高质量机会

### 高层职位识别
- **决策层**: 总经理/CEO、厂长、COO
- **执行层**: 生产总监、技术总监、采购总监
- **专业层**: 物联网总监、智能制造经理、研发总监

## 🔍 高层信息收集策略

### 1. LinkedIn搜索法
```
搜索关键词组合:
- "江南大学" + "物联网" + "总监"
- "公司名称" + "总经理"
- "无锡" + "智能制造" + "经理"
```

**操作步骤**:
1. 使用LinkedIn高级搜索
2. 筛选"当前公司" + "职位级别"
3. 查看校友标签和共同联系人
4. 分析工作经历和专业背景

### 2. 企查查/天眼查查询法
**查找路径**:
- 搜索企业名称
- 查看"主要人员"标签
- 记录法定代表人、董事、监事、高管信息

**信息获取**:
- 姓名、职位、持股比例
- 任职时间、入职时间
- 关联企业信息

### 3. 企业官网突破法
**查找位置**:
- "关于我们" > "领导班子"
- "公司简介" > "管理团队"
- "投资者关系" > "高管信息"
- "招聘页面" > "联系我们"

### 4. 行业协会资源法
**协会类型**:
- 无锡市物联网行业协会
- 江苏省制造业协会
- 中国智能制造系统解决方案供应商联盟

**获取方式**:
- 成为协会会员获取通讯录
- 参加协会活动直接接触
- 通过协会秘书处咨询

## 📞 接触策略与话术

### 初次接触原则
1. **校友优先**: 先找校友身份的高层
2. **价值先行**: 先提供价值再求帮助
3. **精准表达**: 明确需求和时间安排
4. **礼貌专业**: 体现专业性和诚意

### 联系方式获取
**优先顺序**:
1. LinkedIn直接联系
2. 企业官网邮箱/电话
3. 通过共同校友介绍
4. 协会活动名片交换
5. 展会直接交流

### 高层沟通模板

#### LinkedIn消息模板
```
您好[姓名]，我是江南大学物联网学院[届别]毕业生[您的姓名]。

在LinkedIn看到您在[公司]担任[职位]，我对您在物联网领域的成就非常敬佩。

我的朋友正在创业，希望于[时间]来无锡考察相关工厂。

作为校友，希望能有机会向您请教行业发展的宝贵经验。

期待您的指导！
```

#### 微信/电话联系模板
```
[姓名]您好，我是江南大学物联网学院[届别]毕业生[您的姓名]。

得知您在[公司]担任[职位]，我一直关注贵公司在物联网/智能制造领域的发展。

我的朋友[朋友姓名]正在[行业]创业，准备来无锡进行工厂考察。

希望能有机会当面请教您关于[具体领域]的经验和建议。

如果您方便的话，能否安排一次简短的交流？

联系方式: [您的电话/微信]
```

## 📋 考察准备清单

### 高层会面准备
- [ ] 企业基本信息（成立时间、主营业务、规模）
- [ ] 高层背景信息（毕业院校、专业、从业经历）
- [ ] 考察目的和具体需求清单
- [ ] 公司简介和团队介绍资料
- [ ] 名片和介绍信

### 问题清单准备
**技术问题**:
- 贵公司在物联网/智能制造方面的技术特色？
- 遇到的主要技术挑战和解决方案？

**管理问题**:
- 企业数字化转型的经验和教训？
- 对创业者的建议和忠告？

**合作问题**:
- 是否有供应商/合作伙伴的需求？
- 对新技术的应用态度和计划？

## 📊 跟进策略

### 接触后的跟进
1. **24小时内**: 发送感谢信息
2. **3天内**: 补充相关资料
3. **1周内**: 确认考察安排
4. **持续跟进**: 定期分享行业资讯

### 关系维护
- 分享有价值的信息和资源
- 邀请参加相关活动
- 建立长期互助关系

## ⚠️ 注意事项

### 避免误区
1. **不要贸然打扰**: 确认对方工作时间
2. **不要过分要求**: 尊重对方时间和意愿
3. **不要虚假信息**: 诚实介绍背景和需求
4. **不要一锤子买卖**: 建立长期关系

### 成功率提升
- **校友身份**: 利用共同母校优势
- **专业背景**: 展示相关专业知识
- **价值提供**: 先思考能为对方做什么
- **多次跟进**: 要有耐心和毅力

## 📈 预期效果

### 短期目标（1个月）
- 识别5-10位目标高层
- 建立3-5位有效联系
- 获得1-2次考察机会

### 长期目标（3个月）
- 建立稳定的高层人脉网络
- 形成持续的合作关系
- 成为行业资源连接者
