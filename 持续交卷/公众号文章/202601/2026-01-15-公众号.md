## 🔧 算法模块

### 整数平方根算法实现

#### 题目描述

实现一个函数 `mySqrt(int n)`，计算非负整数 n 的平方根的整数部分。要求不使用内置的平方根函数，如 Java 的 `Math.sqrt()`。

#### 解题思路

采用二分查找算法的思想来解决这个问题：

1. **确定搜索范围**：平方根的整数部分一定在 0 到 n 之间
2. **二分查找过程**：
   - 计算中间值 mid
   - 比较 mid * mid 与 n 的大小关系
   - 如果相等，直接返回 mid
   - 如果 mid * mid > n，说明平方根在左侧，缩小右边界
   - 如果 mid * mid < n，说明平方根在右侧，缩小左边界
3. **循环结束条件**：当左边界超过右边界时，right 即为所求的整数平方根

#### 代码实现

```java
class Solution {

    int mySqrt(int n) {
        if (n < 1) {
            return n;
        }

        int left = 1;
        int right = n;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            // 使用除法防止 mid*mid 溢出
            int sqrt = n / mid;

            if (sqrt == mid) {
                return mid;
            }
            // mid大于平方根，需要向左搜索
            if (mid > sqrt) {
                right = mid - 1;
            }
            // mid小于平方根，需要向右搜索
            else {
                left = mid + 1;
            }
        }

        // 循环结束时，right就是最大的满足平凡根的整数
        return right;
    }
}
```

#### 复杂度分析

- **时间复杂度**：O(log n)，二分查找的经典时间复杂度，对数级别
- **空间复杂度**：O(1)，只使用了常数个变量，无额外空间开销
- **执行效率**：相比线性查找，效率大幅提升，特别适合大数值计算

#### 关键优化点

1. **防溢出处理**：使用 `n / mid` 代替 `mid * mid`，避免了整数溢出的风险
2. **边界处理**：对 n < 1 的特殊情况单独处理，保证函数的鲁棒性
3. **整数运算**：全部使用整数运算，避免浮点数精度问题

#### 算法可视化

```
假设 n = 16，寻找 √16 = 4

初始状态：left = 1, right = 16

第一次迭代：
mid = 1 + (16-1)/2 = 8
8 * 8 = 64 > 16，说明平方根在左侧，right = 8-1 = 7

第二次迭代：
mid = 1 + (7-1)/2 = 4
4 * 4 = 16 == 16，找到结果，返回 4
```

这种二分查找的思想在算法设计中有着广泛的应用，体现了分治算法的核心理念。
