## 🎯 快速开始

### 30 秒选型

```
写代码 & 深度改仓库 → AI IDE (Cursor/Trae)
批量改动 & 自动化   → AI CLI (Claude Code/Gemini CLI)
调研 & 方案设计     → AI 模型 (Claude/DeepSeek)
生成图片/视频       → 多模态工具 (可灵/Sora)
自动化工作流        → Agent 平台 (Coze)
```

### 推荐组合

| 预算 | 主力 IDE | CLI 补强 | 方案设计 | 总成本 |
|-----|---------|---------|---------|--------|
| 充足 | Cursor | Claude Code | Claude | ~$60/月 |
| 中等 | Cursor | Gemini CLI | DeepSeek | ~$20/月 |
| 敏感 | Trae | Gemini CLI | DeepSeek | 免费 |

## 🖥️ AI IDE 使用体验

### 主力工具

#### Cursor
- **定位**：功能最全面的 AI IDE
- **使用场景**：方案设计、日常工作、结合本地知识库
- **优势**：Agent 模式强大、Composer 功能全面、Bug Finder 实验性
- **劣势**：价格较贵（$20-200/月）、用量计费变化
- **推荐指数**：⭐⭐⭐⭐⭐
- **我的评价**：如果不考虑价格，基本可以 only one 使用

#### Trae
- **定位**：Cursor 的最佳平替
- **使用场景**：快速构建原型、MCP、网站、轻量级后端
- **优势**：Solo 模式适合快速原型、实时跟踪能力、价格友好
- **劣势**：资料与生态相对较少
- **推荐指数**：⭐⭐⭐⭐
- **我的评价**：快速闭环，适合试错

#### Qoder
- **定位**：中大型后端项目专用
- **使用场景**：工作项目开发、存量代码理解
- **优势**：Repo Wiki 强大、Qwen-Coder 后端能力强
- **劣势**：相对小众、不同项目效果波动
- **推荐指数**：⭐⭐⭐⭐
- **我的评价**：借助 repo wiki 让 AI 更好理解现有业务架构

## ⌨️ AI CLI 工具

### 核心定位
CLI 是 IDE 的补充：
1. **能力层面补充**：Claude Code 能力最强
2. **免费额度**：Gemini CLI、Qwen CLI 可做日常工作

### 工具对比

| 工具 | 定位 | 优势 | 劣势 | 价格 | 推荐指数 |
|-----|------|------|------|------|---------|
| **Claude Code** | 最强 CLI | 推理能力顶级 | 价格贵 | $20-100/月 | ⭐⭐⭐⭐⭐ |
| **Gemini CLI** | 免费首选 | 1000/天免费额度 | 复杂工程一般 | 免费 | ⭐⭐⭐⭐⭐ |
| **Qwen CLI** | 中文优化 | 2000/天免费额度 | 深度推理有限 | 免费 | ⭐⭐⭐⭐ |
| **Aider** | 开源 Git 集成 | 多模型支持 | 仅限终端 | API 成本 | ⭐⭐⭐⭐ |
| **Cline** | VS Code 插件 | 自主执行 | 需自带 API | 免费 | ⭐⭐⭐⭐ |

### 我的使用方式
- **Claude Code**：关键方案使用（贵但强）
- **Gemini CLI**：长上下文方案调研（免费额度）
- **Qwen CLI**：中小项目开发（免费额度）

## ⚠️ 避坑总结

### IDE 使用
1. **不要一次改太多**：拆成 3-7 个子任务
2. **明确改动范围**：告诉 AI 哪些能改、哪些不能改
3. **强制代码审查**：每步都要看 diff
4. **关注成本变化**：定期检查订阅

### CLI 使用
1. **关闭自动执行**：人工确认关键命令
2. **保持 Git 干净**：改动前确保工作区干净
3. **创建检查点**：重要节点手动保存

### 模型使用
1. **交叉验证**：关键结论用第二模型确认
2. **敏感信息脱敏**：上传前处理客户数据
3. **来源核验**：调研结论要抽查原文
