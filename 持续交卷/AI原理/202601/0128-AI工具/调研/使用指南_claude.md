## AI IDE

### Cursor

**主要使用场景**:功能最全面的AI IDE

**优势**:
- 基于VS Code,界面熟悉
- Agent模式支持多文件自主重构
- Composer功能强大,支持复杂的代码生成
- 提供实验性Bug Finder
- 上下文感知的AI建议透明且易于审查
- 与GitHub深度集成

**劣势**:
- 价格较贵($20/月 Pro版,$40/月 Business版)
- 最近改为基于使用量的计费,增加了计费不可预测性
- 界面相对复杂
- 使用限制变化导致工作流中断

**价格**: Pro $20/月,Business $40/月

**我的使用场景**: 主要用于方案设计等日常工作场景,结合本地知识库使用。如果不考虑价格因素,基本可以作为唯一工具使用。

**适合人群**: 需要先进模型、VS Code深度集成和大型代码库管理的专业开发者

---

### Windsurf (原Codeium)

**主要使用场景**: Cursor的最佳平替

**优势**:
- Cascade AI提供更强的自主性,可以主动建议并应用多步骤跨文件更改
- 价格相对便宜($15/月,比Cursor便宜$5)
- 支持40+种IDE,不仅限于VS Code
- Fast Context专有模型用于快速代码库理解
- SWE-1.5模型速度是Sonnet 4.5的13倍
- AI驱动的Codemaps用于可视化代码导航
- 提供企业级安全和管理功能
- 流畅的UI设计,类似Apple产品

**劣势**:
- Cascade的过度自主性有时需要频繁干预
- 在复杂重构时可能会破坏现有功能
- 定价模型包含"model flow action credits"等不太清晰的概念

**价格**: $15/月(Pro版)

**我的使用场景**: 类似Cursor,但价格更友好,适合预算有限的开发者

**适合人群**: 需要跨IDE工作、大规模多文件重构或企业合规要求的团队

### Zed

**主要使用场景**: 速度优先的轻量级编辑器

**优势**:
- 使用Rust编写,提供原生性能和GPU加速
- 极快的响应速度(120fps AI辅助编码)
- 内置实时多人协作功能
- 开源且免费
- 创新的Edit Prediction功能
- 界面简洁流畅

**劣势**:
- AI功能相对基础,不如Cursor深入
- 扩展生态系统较小且较新
- 仅支持Mac和Linux(Windows处于早期访问)
- 学习曲线较陡

**价格**: 免费且开源,可选付费AI服务按使用付费

**适合人群**: 注重性能、实时协作和开源的开发者团队

## AI CLI工具

CLI工具适合作为IDE的补充:
1. 能力层面的补充(如Claude Code能力强)
2. 提供免费额度,可做日常免费工作

### Claude Code

**定位**: 最强大的AI CLI工具

**主要特性**:
- 理解代码库并通过自然语言命令加速编码
- 执行常规任务、解释复杂代码、处理git工作流
- 终端、IDE和Web三种访问方式
- 支持Opus 4.5、Sonnet 4.5和Haiku 4.5模型
- 集成到VS Code、Cursor、Windsurf和JetBrains
- 支持Checkpointing(检查点),可在复杂任务中保存和恢复状态
- Subagents(子代理)用于委托专业任务
- Hooks自动化在特定点触发操作
- 支持MCP(Model Context Protocol)扩展
- 背景任务支持长时间运行的进程

**优势**:
- 能力最强,推理能力出色
- 深度集成到终端工作流
- 透明的权限系统
- 支持Skills(技能)系统进行任务定制
- 支持Chrome扩展进行浏览器自动化

**劣势**:
- 价格最贵(需要Claude Pro $20/月或Max $100/月订阅,或API访问)
- 实际使用成本高(约$8/90分钟密集工作)
- 需要熟悉终端工作流

**价格**: Pro $20/月,Max $100/月,或按API使用付费

**我的使用场景**: 只在关键方案中使用,因为价格最贵但能力最强

**适合人群**: 处理复杂大型代码库、需要高级推理能力、愿意为质量付费的专业开发团队

**安装**: 
```bash
npm install -g @anthropic-ai/claude-code
```

**基本用法**:
```bash
# 进入项目目录
cd /path/to/project

# 启动Claude Code
claude

# 使用特定模型
claude --model opus
```

### Gemini CLI

**定位**: 最慷慨的免费AI CLI

**主要特性**:
- Google的开源CLI,直接在终端访问Gemini
- 免费层60请求/分钟,1000请求/天(个人Google账户)
- Gemini 2.5 Pro(后升级到Gemini 3),100万token上下文窗口
- 内置Google搜索集成
- 支持MCP扩展自定义工具
- 文件操作、Shell命令、Web抓取
- 支持GEMINI.md上下文文件
- Checkpointing和Token缓存

**优势**:
- 业界最慷慨的免费使用额度
- 完全开源(Apache 2.0)
- 与Google生态系统深度集成
- 轻量级快速响应
- 多模态能力(文本、图像、文档)

**劣势**:
- 推理能力不如Claude Code
- 对复杂任务的规划能力有限
- 可能在用户数据上训练

**价格**: 免费(个人Google账户),或付费升级到Google AI Pro/Ultra

**我的使用场景**: 有免费额度,适合做长上下文的方案调研

**适合人群**: AI编码工具新手、需要频繁研究和文档查找、学习新框架的开发者

**安装**:
```bash
npm install -g @google/gemini-cli
```

**基本用法**:
```bash
# 登录Google账户
gemini

# 使用命令
gemini > Explain this codebase architecture
```

### Qwen CLI

**定位**: Gemini CLI的中文优化版本

**主要特性**:
- 基于Qwen3-Coder模型(480B MoE,35B激活)
- 从Gemini CLI fork并针对Qwen模型优化
- 免费层2000请求/天(Qwen OAuth账户)
- 60请求/分钟速率限制
- 模型无关架构,可连接任何OpenAI兼容API
- 支持通过OpenRouter使用其他模型

**优势**:
- 非常慷慨的免费层(2000请求/天)
- 对中文和代码任务优化良好
- 可配置使用其他模型(GPT、Claude等)
- Gemini CLI的完全开放版本

**劣势**:
- 默认模型缺乏深度推理能力
- 继承了Gemini CLI的一些UI小问题
- 可能在用户数据上训练

**价格**: 免费(Qwen账户),或通过API付费使用其他模型

**我的使用场景**: 有免费额度,适合做中小项目开发

**安装**:
```bash
npx @qwen-code/qwen-code@latest
```

### Aider

**定位**: 开源终端AI配对编程工具

**主要特性**:
- 完全开源的CLI工具
- 直接与本地Git仓库工作
- 自动生成合理的提交消息
- 代码库映射用于大型项目
- 支持多种编程语言
- 可在IDE内使用(通过注释触发)
- 支持图像和网页作为上下文
- 语音输入支持
- 自动Lint和测试

**优势**:
- 完全免费(仅需API密钥成本)
- Git深度集成
- 强大的代码库理解能力
- 支持任意LLM(OpenAI、Anthropic、本地Ollama等)
- 隐私优先,可完全本地运行

**劣势**:
- 仅限终端界面(有实验性浏览器UI)
- CLI学习曲线较陡
- 缺少GUI可能对某些用户不友好

**价格**: 开源免费,仅需支付API成本

**适合人群**: 隐私意识强、需要本地部署或严格控制模型选择的团队

**安装**:
```bash
python -m pip install aider-install
aider-install
```

**基本用法**:
```bash
cd /to/your/project

# 使用DeepSeek
aider --model deepseek --api-key deepseek=<key>

# 使用Claude
aider --model sonnet --api-key anthropic=<key>
```

## 使用建议和最佳实践

### IDE选择建议

1. **预算充足且需要最强能力**: Cursor
2. **预算有限但需要全功能**: Windsurf
3. **注重速度和协作**: Zed
4. **快速原型开发**: Trae或Replit
5. **后端项目**: Qoder
6. **企业JetBrains用户**: JetBrains AI Assistant
7. **VS Code忠实用户**: GitHub Copilot

### CLI工具选择建议

1. **最强能力,预算充足**: Claude Code
2. **免费学习和调研**: Gemini CLI或Qwen CLI
3. **开源和隐私优先**: Aider或Cline
4. **平台无关性**: Continue

### 工作流建议

1. **方案设计阶段**: Claude或Gemini + NotebookLM生成架构图
2. **编码阶段**: Cursor/Windsurf + Claude Code CLI
3. **快速原型**: Trae或Replit
4. **文档和可视化**: NotebookLM + Nano Banana
5. **视频内容**: Sora或可灵 + 剪映后期

### 成本优化建议

1. **利用免费层**: Gemini CLI、Qwen CLI的免费额度用于日常开发
2. **按需付费**: 关键任务使用Claude Code,日常使用免费工具
3. **开源优先**: 考虑Aider、Cline等开源工具,仅支付API成本
4. **混合策略**: IDE用Windsurf(便宜),CLI用Gemini(免费),关键时刻用Claude Code

## 总结

AI工具生态系统正在快速发展。选择合适的工具取决于:

1. **预算**: 从完全免费(Gemini CLI)到高端订阅(Claude Code)
2. **使用场景**: IDE内开发 vs 终端工作流 vs 快速原型
3. **技能水平**: GUI友好工具 vs CLI强大工具
4. **隐私要求**: 云服务 vs 本地/自托管方案
5. **团队规模**: 个人使用 vs 企业部署

建议采用混合策略,在不同场景下使用最合适的工具,以平衡成本、效率和质量。定期评估新工具,因为这个领域发展非常快速。
