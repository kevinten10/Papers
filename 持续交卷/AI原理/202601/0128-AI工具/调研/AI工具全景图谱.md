# AI 工具全景图谱（2026年1月版）

> **文档定位**：系统性梳理当前 AI 工具生态，建立统一的分类体系和对比框架
> 
> **适用人群**：开发者、技术决策者、AI 工具学习者
> 
> **更新周期**：建议每季度更新一次

---

## 一、工具分类体系

### 1.1 五大核心类别

```
AI 工具生态
├── 🖥️ AI IDE（智能开发环境）
│   ├── 核心定位：代码生成、项目重构、调试协同
│   ├── 代表工具：Cursor、Windsurf、Trae、Qoder
│   └── 使用场景：日常开发主战场
│
├── ⌨️ AI CLI（命令行工具）
│   ├── 核心定位：批量处理、自动化、长任务推进
│   ├── 代表工具：Claude Code、Gemini CLI、Aider
│   └── 使用场景：IDE 补强层
│
├── 🧠 AI 模型/平台（对话与推理）
│   ├── 核心定位：方案设计、调研总结、知识问答
│   ├── 代表工具：Claude、GPT、Gemini、DeepSeek
│   └── 使用场景：决策支持
│
├── 🎨 AI 多模态工具（内容生成）
│   ├── 核心定位：图像、视频、3D、音频生成
│   ├── 代表工具：Sora、可灵、Meshy、NotebookLM
│   └── 使用场景：创意产出
│
└── 🤖 AI Agent/智能体平台
    ├── 核心定位：工作流编排、自动化任务
    ├── 代表工具：Coze、Dify、AutoGPT
    └── 使用场景：流程自动化
```

### 1.2 选型速查表

| 你的需求 | 首选类别 | 次选类别 | 避坑提示 |
|---------|---------|---------|---------|
| 写代码/改项目 | AI IDE | AI CLI | 不要一次让 AI 改太多文件 |
| 调研/写方案 | AI 模型 | AI IDE | 关键结论要交叉验证 |
| 批量改动/重构 | AI CLI | AI IDE | 必须先给范围限制 |
| 生成图片/视频 | 多模态工具 | AI 模型 | 注意版权和隐私 |
| 自动化工作流 | Agent 平台 | AI CLI | 先约束权限边界 |

### 2.2 详细评测补充

#### Windsurf（原 Codeium）

**核心优势：**
- **Cascade AI**：主动建议并应用多步骤跨文件更改
- **SWE-1.5 模型**：速度是 Sonnet 4.5 的 13 倍
- **Flow 模式**：上下文理解极其丝滑
- **价格优势**：$15/月，比 Cursor 便宜 $5

**适用场景：**
- 复杂逻辑重构
- 多文件协作项目
- 预算敏感但需全功能

**避坑指南：**
- Cascade 过度自主性有时需要干预
- 必须明确限制改动范围

#### Zed

**核心优势：**
- **性能**：Rust 编写，120fps AI 辅助编码
- **协作**：内置实时多人协作
- **开源**：完全开源免费
- **跨平台**：macOS/Linux/Windows

**适用场景：**
- 追求极致性能
- 团队协作开发
- 开源爱好者

**局限性：**
- AI 功能相对基础
- 扩展生态较小

#### Replit

**核心优势：**
- **云端一体**：开发、托管、数据库集成
- **Agent 3**：可自主工作 200 分钟
- **一键部署**：无需配置环境
- **实时协作**：适合教学场景

**适用场景：**
- 快速原型验证
- 编程教学
- 分布式团队协作

**避坑指南：**
- 私有代码需谨慎
- 复杂本地依赖支持有限

## 三、AI CLI 工具全景

### 3.1 能力对比矩阵

| 工具 | 核心能力 | 模型支持 | 免费额度 | 价格 | 推荐指数 |
|-----|---------|---------|---------|------|---------|
| **Claude Code** | 最强推理 | Claude 3.5 | 无 | $20-100/月 | ⭐⭐⭐⭐⭐ |
| **Gemini CLI** | 长上下文 | Gemini 2.5 | 1000/天 | 免费 | ⭐⭐⭐⭐⭐ |
| **Qwen CLI** | 中文优化 | Qwen3 | 2000/天 | 免费 | ⭐⭐⭐⭐ |
| **Aider** | Git 集成 | 多模型 | 无限制 | 仅 API | ⭐⭐⭐⭐ |
| **Cline** | VS Code 集成 | 多模型 | 无限制 | 免费 | ⭐⭐⭐⭐ |
| **Continue** | 开源平台 | 多模型 | 无限制 | 免费 | ⭐⭐⭐⭐ |
| **Codex CLI** | OpenAI 生态 | GPT-4/o1 | 有限 | 订阅制 | ⭐⭐⭐ |

### 3.2 选型建议

**按预算选择：**
- **零预算**：Gemini CLI + Qwen CLI + Aider
- **中等预算**：Claude Code（关键任务）+ Gemini CLI（日常）
- **充足预算**：Claude Code 主力使用

**按场景选择：**
- **复杂重构**：Claude Code
- **日常开发**：Gemini CLI / Qwen CLI
- **Git 工作流**：Aider
- **VS Code 用户**：Cline / Continue
