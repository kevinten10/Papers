## 💻 AI IDE：从“辅助”到“智能体（Agent）”

当前的 AI IDE 已经从简单的“代码补全”进化到了“代理开发（Agentic Development）”阶段。

| 工具 | 核心优势 | 适用场景 | 备注 |
| --- | --- | --- | --- |
| **Cursor** | 生态最稳、模型组合最强（Claude 3.5/o1/o3） | 全能开发、日常主力 | 依然是行业标杆，但价格确实是门槛。 |
| **Windsurf** | **Flow 模式**，上下文理解极其丝滑 | 复杂逻辑重构、多文件协作 | **（强烈补充）** Codeium 推出，目前是 Cursor 最大的对手。 |
| **Trae** | ByteDance 出品，**Solo 模式** 极致优化 | 快速原型、Web 全栈、移动端 demo | 对中文开发者友好，国内访问速度极快。 |
| **Qoder** | **Repo Wiki** + Qwen-Coder 模型深度优化 | 中大型后端、遗留代码库维护 | 阿里系工具，处理 Java/Go 等后端语言有模型加持优势。 |
| **Antigravity** | **Agent-First**，自主规划任务清单并执行 | 自动化项目搭建、端到端开发 | Google 2025 年底发布的杀手锏，基于 Gemini 3。 |
| **Kiro** | **Spec-Driven（规范驱动）**，自动生成架构与测试 | 严谨的企业级开发、架构先行项目 | AWS 出品，适合“文档即代码”的流程，虽然重但稳。 |
| **Codebuddy** | 腾讯云深度集成，一键部署 **EdgeOne/CloudBase** | 落地页、小程序、轻量级全栈应用 | 腾讯系，适合追求“开发即上线”效率的开发者。 |

### 💡 深度补充：

* **Antigravity (Google):** 它的核心不是编辑器，而是 **Agent Manager**。它会把你的需求拆解成任务流（Task List），你可以像面试官一样审批它的计划。它生成的“Artifacts”包含架构图和测试录屏，极大地解决了信任问题。
* **Kiro (AWS):** 你觉得它“重”是因为它强制要求 MCP（Model Context Protocol）集成。它适合那些需要连接私有数据库和 API 文档的严肃项目。

## 🛠️ AI CLI：终端里的超级大脑

CLI 工具现在主要用于处理 IDE 难以触及的“脏活”：系统操作、Git 工作流和跨文件大规模重构。

* **Claude Code:** * **体验：** 确实是“能力天花板”。它能自己运行终端命令、查错、改代码。
* **建议：** 适合解决“死活修不好的 Bug”。


* **Codex CLI (OpenAI):** * **补充：** 这是 OpenAI 在 2025 年中期发布的工具，直接对标 Claude Code。
* **优势：** 深度集成 OpenAI 生态，可以使用最新的 **o4-mini** 模型，推理能力强且 API 成本比 Claude 略低。支持“YOLO 模式”（全自动无干预执行）。


* **Aider:**
* **补充：** 作为开源界的鼻祖，它支持几乎所有 LLM。如果你有自己的 API Key 或是本地运行大模型（Ollama），Aider 是最省钱且最灵活的选择。


* **Gemini / Qwen CLI:**
* **体验：** 适合长上下文分析。比如你把整个项目的日志丢给 Gemini CLI，它能迅速定位链路问题。

## 🌐 AI 模型与平台：多模态与垂直领域

### 1. 通用模型

* **OpenAI (ChatGPT):** 逻辑严密，适合做底层协议设计和复杂算法推导。
* **Claude:** 更有“人味”，代码风格最漂亮，是目前公认的最强编程辅助模型。
* **Gemini:** * **Nano Banana:** 没错，这就是我（Gemini 系列）调用的**高保真图像生成模型**。它擅长处理带有精准文字和复杂构图的示意图。
* **NotebookLM:** 现在的它已经不仅是笔记，2026 版支持生成**多维度的架构视图**和**动态演示音频**。


* **Perplexity / DeepSeek:** * **纠正：** DeepSeek 现在不仅是搜索，其 **DeepSeek-V3/R1** 已经在推理能力上追平了顶级模型，且价格极低。

### 2. 垂直/特色工具

* **氢离子 (H2O.ai / 阿里健康):** * **定位：** 阿里健康推出的专业医学 AI。核心能力是**“低幻觉、高循证”**，每个回答都会标注医学论文或药典的出处。
* **Grok:** * **体验：** 因为其“反审查”特质，在某些灰色地带或成人内容创作上确实限制更少，但其 **Grok-3** 在实时新闻分析上也是顶级的。
* **Coze (扣子):** 字节跳动出品，是目前国内最成熟的 Agent 搭建平台，适合把日常琐事自动化。

## 🎬 AI 视频与 3D：视觉生成的爆发

### 1. 视频生成（非“博主”，是模型）

* **Kling (可灵):** 快手出品。目前在光影处理和动作连贯性上属于全球第一梯队，非常适合做短视频素材。
* **Sora:** OpenAI 的视频模型，更倾向于“电影级”的质感，但目前的调用门槛依然较高。
* **剪映/美图 AI:** 侧重于**工作流集成**，比如一键数字人、自动对齐口型等。

### 2. 3D 模型生成

* **Meshy:** 3D 建模师的噩梦/福音。生成的贴图和拓扑结构已经可以直接用于游戏引擎。
* **混元 3D:** * **补充：** 腾讯出品。优势在于**“图生 3D”**，特别是对于中文风格的角色、古风建筑的理解非常精准，生成的模型在低多边形（Low-Poly）优化上做得很好。
