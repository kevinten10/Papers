## 1. 核心选型逻辑：三句话原则

*   **写代码并与仓库深度交互**：优先用 **AI IDE**（Cursor/Trae/Windsurf）。
*   **补齐“能力上限”或批量自动化**：使用 **AI CLI**（Claude Code/Aider/OpenCode）。
*   **调研、总结与多模态产出**：使用 **模型站点/垂类工具**（Perplexity/NotebookLM/Kling/Meshy）。

**黄金组合建议**：
- **极致效率**：`Cursor Pro (主 IDE) + Aider (补强 CLI) + Perplexity (调研) + Claude 3.5 (核心大脑)`
- **国产白嫖**：`Trae (主 IDE) + DeepSeek R1 (搜索/算力) + Kimi (长文档) + Coze.cn (工作流)`

## 6. 实战避坑与充值建议 (Pricing Strategy)

### 避坑指南 (Pitfalls)
1.  **禁止冗余订阅**：Cursor 与 Windsurf 选一个即可，功能重叠度 90%。
2.  **网络风控**：充值 Claude Pro 前确保网络纯净，避免因 IP 污染被误封。
3.  **代码漂移**：在 IDE 内一次性修改文件不要超过 10 个，AI 会在后续文件中丢失上下文。
4.  **成本预警**：使用 Claude Code 等 CLI 时务必监控 Token，防止“一觉醒来破产”。
5.  **隐私开关**：处理敏感项目时，务必关闭 IDE 的“云端训练 (Training)”选项。
