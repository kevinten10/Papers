# 文章处理统一入口

## 使用方式

将待处理的文章路径替换到下方 prompt 中，直接发给 AI 即可。AI 会自动完成分级、路由、处理。

---

## 标准 Prompt

```
请处理以下文章，按照持续交卷的工作流自动执行：

待处理文件：
- @[文件路径1]
- @[文件路径2]
- ...

请按以下步骤执行：

### 步骤 1：内容分级
参考 @持续交卷/社媒分发rule.md 第一步的分级标准，对每个文件判定 A/B/C 级：
- A级（独立主题、有深度、3000字以上）→ 走多平台分发流程
- B级（日常笔记、碎片知识）→ 走公众号文章处理流程
- C级（纯草稿/备忘）→ 跳过，不处理

输出分级结果表格，等待确认后再继续。

### 步骤 2：按分级路由处理

**B 级文件**：
参考 @持续交卷/文章处理rule.md ，执行以下操作：
1. 识别模块类型（阅读笔记/英语资讯/算法/技术写作/AI原理）
2. 判断同日期是否有多个文件需要聚合
3. 按模块专用规则转换为公众号文章
4. 输出到 持续交卷/公众号文章/YYYYMM/YYYY-MM-DD-公众号.md

**A 级文件**：
参考 @持续交卷/社媒分发rule.md ，执行以下操作：
1. 生成多平台改写（微信公众号/知乎/小红书/X Twitter）
2. 输出 [原文件名]-社媒版.md（与原文同目录）
3. 列出需要生成的配图清单（封面+正文图+金句卡）
4. 等待确认后生成配图

### 步骤 3：敏感信息检查
对所有生成的内容检查：密码、token、API key、真实连接串、隐私信息。
报告检查结果。

### 步骤 4：输出汇总
列出所有生成的文件清单，标注状态。
```

## 快捷 Prompt（日常笔记批处理）

适用于日常 B 级笔记的快速处理，跳过分级步骤：

```
参考 @持续交卷/文章处理rule.md ，使用日期聚合模式处理以下文件：

- @[文件路径1]
- @[文件路径2]
- ...

要求：
1. 识别各文件的模块类型
2. 聚合为公众号日报文章
3. 输出到 持续交卷/公众号文章/ 对应目录
```

---

## 快捷 Prompt（深度文章多平台分发）

适用于 A 级深度文章：

```
参考 @持续交卷/社媒分发rule.md ，对以下文章进行多平台分发处理：

原文：@[文件路径]

要求：
1. 生成四个平台的改写版本（微信/知乎/小红书/X）
2. 输出 [原文件名]-社媒版.md
3. 列出配图生成清单
4. 完成敏感信息检查
```

## 示例

### 示例 1：处理一天的日常笔记

```
参考 @持续交卷/文章处理rule.md ，使用日期聚合模式处理以下文件：

- @持续交卷/算法/202601/0109-八股.md
- @持续交卷/算法/202601/0109交替打印.java
- @持续交卷/英语资讯/202601/0109-EN.md
- @持续交卷/阅读笔记/202601/0109-资讯.md

要求：识别模块类型，聚合为公众号日报，输出到 持续交卷/公众号文章/202601/
```

### 示例 2：深度文章全平台分发

```
参考 @持续交卷/社媒分发rule.md ，对以下文章进行多平台分发处理：

原文：@持续交卷/AI原理/202603/0310-AICoding.md

要求：生成四平台改写 + 配图清单 + 敏感信息检查
```

### 示例 3：自动分级处理（不确定级别时）

```
请处理以下文章，按照持续交卷的工作流自动执行：

待处理文件：
- @持续交卷/AI原理/202601/0129-supabase.md
- @持续交卷/阅读笔记/202601/0126-资讯.md

先进行内容分级（参考 @持续交卷/社媒分发rule.md），确认后再按对应流程处理。
```
