# 后端八股文集合

## 🎯 学习目标
系统整理后端开发面试中常见的理论知识点，涵盖数据库、网络、系统设计、编程语言、框架等核心领域。通过理解底层原理，提升技术深度和面试竞争力。

## 📚 知识体系总览

### 1. 数据库系统 (Database Systems)
#### MySQL 基础
- **索引原理**：B+树结构、聚簇索引、非聚簇索引
- **事务特性**：ACID、隔离级别、MVCC
- **锁机制**：行锁、表锁、死锁检测
- **查询优化**：EXPLAIN、慢查询分析、索引优化

#### Redis 缓存
- **数据类型**：String、Hash、List、Set、ZSet
- **持久化**：RDB、AOF、混合持久化
- **内存淘汰**：LRU、LFU、随机淘汰策略
- **集群模式**：主从复制、哨兵模式、Cluster

#### MongoDB 文档数据库
- **文档模型**：JSON/BSON、嵌入式文档
- **索引类型**：单字段、复合、地理空间索引
- **分片集群**：分片键、平衡器、配置服务器

### 2. 网络协议 (Network Protocols)
#### HTTP/HTTPS 协议
- **请求方法**：GET、POST、PUT、DELETE、PATCH、OPTIONS
- **状态码分类**：1xx信息、2xx成功、3xx重定向、4xx客户端错误、5xx服务器错误
- **头部字段**：Content-Type、Authorization、Cache-Control
- **HTTPS握手**：证书验证、非对称加密、对称加密

#### TCP/IP 协议栈
- **三次握手**：SYN、SYN-ACK、ACK 建立连接
- **四次挥手**：FIN、ACK、FIN、ACK 断开连接
- **流量控制**：滑动窗口、拥塞控制
- **TCP优化**：Nagle算法、延迟ACK、TIME_WAIT

#### WebSocket 协议
- **握手过程**：HTTP升级、Sec-WebSocket-Key
- **帧格式**：数据帧、控制帧、掩码处理
- **心跳机制**：Ping/Pong 保活连接

### 3. 系统设计 (System Design)
#### 分布式系统
- **CAP理论**：一致性、可用性、分区容错性
- **BASE理论**：基本可用、软状态、最终一致性
- **一致性哈希**：虚拟节点、数据分布、rehash
- **服务发现**：客户端发现、服务端发现、注册中心

#### 微服务架构
- **服务拆分**：按业务拆分、按数据拆分
- **通信方式**：同步REST、异步消息队列
- **API网关**：路由转发、认证授权、限流熔断
- **配置中心**：配置管理、动态更新、版本控制

#### 缓存设计
- **缓存策略**：Cache-Aside、Write-Through、Write-Behind
- **缓存问题**：穿透、击穿、雪崩、热点key
- **多级缓存**：浏览器缓存、CDN、应用缓存、分布式缓存

### 4. 编程语言特性 (Language Features)
#### Java 语言
- **JVM内存模型**：堆、栈、方法区、程序计数器
- **垃圾回收**：新生代、老年代、垃圾回收器选择
- **并发编程**：线程状态、synchronized、volatile、CAS
- **集合框架**：ArrayList、LinkedList、HashMap、ConcurrentHashMap

#### Go 语言
- **协程机制**：goroutine调度、GPM模型
- **channel通信**：无缓冲、有缓冲、select多路复用
- **内存管理**：垃圾回收、三色标记、写屏障
- **context包**：上下文传递、超时控制、取消操作

#### Python 语言
- **GIL机制**：全局解释器锁、线程安全、多进程替代
- **异步编程**：asyncio、协程、事件循环
- **内存管理**：引用计数、垃圾回收、内存池
- **装饰器模式**：函数装饰器、类装饰器、参数传递

### 5. 框架与中间件 (Frameworks & Middleware)
#### Spring 框架
- **IOC容器**：依赖注入、Bean生命周期、作用域
- **AOP编程**：切面、通知、连接点、切入点
- **事务管理**：声明式事务、编程式事务、传播行为
- **Spring Boot**：自动配置、Starter、Actuator监控

#### Django 框架
- **ORM系统**：模型定义、查询API、迁移管理
- **中间件**：请求处理流程、自定义中间件
- **缓存框架**：缓存后端、缓存装饰器、页面缓存
- **认证系统**：用户模型、权限控制、Session管理

#### Express.js 框架
- **中间件模式**：应用级、路由级、错误处理中间件
- **路由系统**：路径匹配、参数提取、正则路由
- **错误处理**：同步错误、异步错误、404处理
- **安全考虑**：Helmet安全头、CORS、输入验证

### 6. 算法与数据结构 (Algorithms & Data Structures)
#### 基础数据结构
- **线性结构**：数组、链表、栈、队列、哈希表
- **树形结构**：二叉树、平衡二叉树、B树、B+树
- **图结构**：邻接表、邻接矩阵、拓扑排序

#### 经典算法
- **排序算法**：快速排序、归并排序、堆排序
- **查找算法**：二分查找、哈希查找、树查找
- **动态规划**：最长子序列、背包问题、状态转移
- **贪心算法**：活动选择、霍夫曼编码、最小生成树

#### 设计模式
- **创建型模式**：单例、工厂、建造者、原型
- **结构型模式**：适配器、装饰器、外观、代理
- **行为型模式**：观察者、策略、模板方法、状态

## 🔍 重点复习清单

### 高频考点
1. **数据库索引原理** - B+树结构、索引优化
2. **TCP三次握手** - 连接建立过程、状态转换
3. **JVM垃圾回收** - 分代收集、GC算法选择
4. **Redis数据类型** - String、Hash应用场景
5. **Spring IOC/AOP** - 依赖注入、切面编程
6. **分布式CAP理论** - 三者取舍、一致性模型

### 深入理解点
1. **MVCC机制** - 多版本并发控制、读写冲突解决
2. **一致性哈希** - 分布式数据分布、rehash问题
3. **协程调度** - GMP模型、抢占式调度
4. **缓存穿透解决方案** - 布隆过滤器、缓存空值
5. **微服务拆分原则** - 按业务边界、数据一致性

## 📈 学习建议

1. **分层学习**：从基础概念到深入原理循序渐进
2. **结合实践**：理论知识与实际项目相结合
3. **定期复习**：设置复习周期，加深记忆
4. **举一反三**：理解原理后扩展到相似问题
5. **源码分析**：阅读框架源码，理解实现细节
