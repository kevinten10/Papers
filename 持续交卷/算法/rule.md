# 🧮 算法学习指南

## 🎯 学习目标
通过每日算法练习，提升编程思维、数据结构理解和问题解决能力。重点培养计算思维和代码优化能力。

## 📝 交卷要求

### 练习要求
- **题目难度**：从简单到中等，循序渐进
- **时间控制**：独立思考30分钟，编码30分钟
- **质量标准**：代码正确，思路清晰，注释完整

### 题目来源
优先选择以下平台：
- **LeetCode**: 算法题库最全，包含详细解题思路
- **力扣 (LeetCode China)**: 中文界面，适合初学者
- **CodeSignal**: 面试导向的算法练习
- **HackerRank**: 包含多种编程语言
