# Java代码评审知识点整理

## 一、性能优化类问题

### 1. sleep限流问题
**问题描述**: 使用Thread.sleep()进行限流控制
**问题分析**: Thread.sleep()会阻塞线程，浪费系统资源，且限流效果不精确
**潜在风险**: 系统资源浪费，性能下降，无法应对突发流量
**解决方案**: 使用专门的限流组件如Guava RateLimiter、Sentinel等

### 2. 分布式系统重复读、重复写的问题
**问题描述**: 在分布式环境下没有考虑数据一致性
**问题分析**: 分布式系统存在网络延迟、节点故障等因素，可能导致重复读写
**潜在风险**: 数据不一致、业务逻辑错误
**解决方案**: 使用分布式锁、幂等设计、乐观锁等机制

**错误代码示例**:
```java
// 分布式环境下，多个节点同时处理同一订单，可能导致重复扣款
public void processOrder(String orderId) {
    // 检查订单状态
    Order order = orderDao.findById(orderId);
    if (order.getStatus() != OrderStatus.PENDING) {
        return; // 可能多个节点同时检查，都通过了
    }

    // 扣款操作
    paymentService.deduct(order.getAmount());
    // 更新订单状态
    order.setStatus(OrderStatus.PAID);
    orderDao.update(order);
}
```

**正确代码示例**:
```java
// 使用分布式锁确保操作原子性
public void processOrder(String orderId) {
    String lockKey = "order:lock:" + orderId;

    try {
        // 获取分布式锁，设置过期时间防止死锁
        boolean locked = redisLock.tryLock(lockKey, 30, TimeUnit.SECONDS);
        if (!locked) {
            throw new BusinessException("订单正在处理中");
        }

        // 双重检查订单状态
        Order order = orderDao.findById(orderId);
        if (order.getStatus() != OrderStatus.PENDING) {
            return;
        }

        // 扣款操作
        paymentService.deduct(order.getAmount());
        // 更新订单状态
        order.setStatus(OrderStatus.PAID);
        orderDao.update(order);

    } finally {
        redisLock.unlock(lockKey);
    }
}
```

### 3. loop上限固定，可能不符合未来id增长
**问题描述**: 循环次数固定死，未来ID增长可能超过限制
**问题分析**: 业务增长导致ID范围扩大，固定上限不再适用
**潜在风险**: 数据处理不完整，业务逻辑错误
**解决方案**: 使用动态查询或配置化的上限值

### 4. 循环嵌套时，可能导致风暴。建议批量化改造
**问题描述**: 多层嵌套循环导致性能问题
**问题分析**: 时间复杂度为O(n^m)，数据量大时性能急剧下降
**潜在风险**: 系统响应慢、CPU占用高、可能导致服务不可用
**解决方案**: 批量处理、优化算法复杂度、使用Map等数据结构

**错误代码示例**:
```java
// 三层嵌套循环，时间复杂度O(n^3)
// 假设userList有1000个用户，roleList有100个角色，permList有50个权限
// 总共需要执行1000*100*50=5,000,000次循环
public void assignPermissions(List<User> userList, List<Role> roleList, List<Permission> permList) {
    for (User user : userList) {           // 外层循环：1000次
        for (Role role : roleList) {        // 中层循环：100次
            for (Permission perm : permList) {  // 内层循环：50次
                // 每次循环都进行数据库插入操作
                userRolePermDao.insert(user.getId(), role.getId(), perm.getId());
            }
        }
    }
}
```

**正确代码示例**:
```java
// 使用批量处理，优化为O(n)复杂度
public void assignPermissions(List<User> userList, List<Role> roleList, List<Permission> permList) {
    // 预先构建权限映射关系
    Map<Long, Set<Long>> rolePermMap = new HashMap<>();
    for (Role role : roleList) {
        Set<Long> permIds = permList.stream()
                .filter(perm -> perm.getRoleId().equals(role.getId()))
                .map(Permission::getId)
                .collect(Collectors.toSet());
        rolePermMap.put(role.getId(), permIds);
    }

    // 批量收集所有需要插入的数据
    List<UserRolePerm> batchData = new ArrayList<>();
    for (User user : userList) {
        for (Role role : roleList) {
            Set<Long> permIds = rolePermMap.get(role.getId());
            for (Long permId : permIds) {
                batchData.add(new UserRolePerm(user.getId(), role.getId(), permId));
            }
        }
    }

    // 批量插入，一次数据库操作搞定
    userRolePermDao.batchInsert(batchData);
}
```

### 5. Map可能有线程不安全问题
**问题描述**: 使用了非线程安全的Map实现如HashMap
**问题分析**: 多线程环境下并发修改可能导致数据不一致
**潜在风险**: 数据竞争、ConcurrentModificationException
**解决方案**: 使用ConcurrentHashMap或Collections.synchronizedMap()

**错误代码示例**:
```java
// 使用HashMap存储缓存数据，多线程环境下不安全
public class CacheManager {
    private static final Map<String, Object> cache = new HashMap<>();

    public static void put(String key, Object value) {
        cache.put(key, value); // 多线程并发put可能导致数据丢失
    }

    public static Object get(String key) {
        return cache.get(key); // 读取时可能读到不一致的数据
    }

    // 在遍历时如果其他线程修改，可能抛出ConcurrentModificationException
    public static void printAll() {
        for (Map.Entry<String, Object> entry : cache.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }
    }
}
```

**正确代码示例**:
```java
// 使用ConcurrentHashMap保证线程安全
public class CacheManager {
    private static final Map<String, Object> cache = new ConcurrentHashMap<>();

    public static void put(String key, Object value) {
        cache.put(key, value); // ConcurrentHashMap保证线程安全
    }

    public static Object get(String key) {
        return cache.get(key);
    }

    // 安全的遍历方式
    public static void printAll() {
        cache.forEach((key, value) ->
            System.out.println(key + ": " + value)
        );
    }

    // 或者使用快照遍历
    public static void printAllSnapshot() {
        Map<String, Object> snapshot = new HashMap<>(cache);
        for (Map.Entry<String, Object> entry : snapshot.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }
    }
}
```

### 6. 全路径引用问题

### 7. 循环内内嵌db/rpc调用，可能导致风暴
**问题描述**: 在循环中进行数据库或RPC调用
**问题分析**: 每次循环都产生网络IO，效率低下
**潜在风险**: 数据库连接池耗尽、服务响应慢
**解决方案**: 批量查询、使用缓存、异步处理

**错误代码示例**:
```java
// 在循环中逐个查询用户信息，效率极低
public List<OrderVO> getOrderDetails(List<Long> orderIds) {
    List<OrderVO> result = new ArrayList<>();

    for (Long orderId : orderIds) {
        // 每次循环都进行一次数据库查询
        Order order = orderDao.findById(orderId);

        // 每次循环都调用用户服务获取用户信息
        UserDTO user = userService.getUserById(order.getUserId());

        // 每次循环都调用商品服务获取商品信息
        List<ProductDTO> products = productService.getProductsByOrderId(orderId);

        OrderVO vo = convertToVO(order, user, products);
        result.add(vo);
    }

    return result;
    // 如果orderIds有1000个，就会产生1000次数据库查询 + 1000次用户服务调用 + 1000次商品服务调用
}
```

**正确代码示例**:
```java
// 使用批量查询和缓存优化性能
public List<OrderVO> getOrderDetails(List<Long> orderIds) {
    // 批量查询订单信息，一次数据库操作
    List<Order> orders = orderDao.findByIds(orderIds);

    // 提取所有用户ID，批量查询用户信息
    Set<Long> userIds = orders.stream()
            .map(Order::getUserId)
            .collect(Collectors.toSet());
    Map<Long, UserDTO> userMap = userService.getUsersByIds(userIds)
            .stream()
            .collect(Collectors.toMap(UserDTO::getId, u -> u));

    // 批量查询商品信息
    Map<Long, List<ProductDTO>> productMap = productService.getProductsByOrderIds(orderIds);

    // 组装数据
    return orders.stream()
            .map(order -> {
                UserDTO user = userMap.get(order.getUserId());
                List<ProductDTO> products = productMap.get(order.getId());
                return convertToVO(order, user, products);
            })
            .collect(Collectors.toList());
    // 总共只有3次网络调用：1次订单查询 + 1次用户查询 + 1次商品查询
}
```

### 19. 生产代码不建议使用递归，前置退出逻辑
**问题描述**: 使用递归算法处理业务逻辑
**问题分析**: 递归深度不可控，可能导致栈溢出
**潜在风险**: StackOverflowError，系统崩溃
**解决方案**: 使用循环+栈数据结构，限制递归深度

### 39. cpu_core * 15，这种可能比较激进。一般是+1，或者4-8倍
**问题描述**: 线程池大小配置过激进
**问题分析**: 线程过多导致上下文切换频繁，CPU资源浪费
**潜在风险**: 性能下降，系统负载过高
**解决方案**: 根据CPU核心数合理配置，通常为CPU核心数+1或4-8倍

### 40. work_queue=1并且使用的Arraysyncqueue的问题
**问题描述**: 线程池使用ArrayBlockingQueue(1)作为工作队列
**问题分析**: 队列容量为1，任务无法缓冲，直接交给线程处理
**潜在风险**: 线程数快速增长，可能导致OOM
**解决方案**: 使用有界队列，配置合适的拒绝策略

## 二、架构设计类问题

### 12. 缺少防腐层设计，内部数据模型使用了外部的契约对象
**问题描述**: 领域模型直接使用外部API的DTO对象
**问题分析**: 外部接口变化时，内部代码需要大量修改
**潜在风险**: 紧耦合，维护困难，违反DDD原则
**解决方案**: 建立防腐层(Anti-Corruption Layer)，内部使用领域对象

**错误代码示例**:
```java
// 直接使用外部API的DTO作为领域对象
@Service
public class OrderService {

    @Autowired
    private ThirdPartyApiClient apiClient;

    // 直接使用外部API返回的DTO
    public void processOrder(ThirdPartyOrderDTO externalOrder) {
        // 领域逻辑直接依赖外部DTO结构
        if (externalOrder.getStatus().equals("PAID")) {
            // 业务处理逻辑
            Order order = new Order();
            order.setExternalId(externalOrder.getId());
            order.setAmount(externalOrder.getTotalAmount());
            order.setUserId(externalOrder.getCustomerId());
            // 当外部API字段名改变时，这里也要跟着改
        }
    }
}

// 外部API DTO直接用于内部存储
@Entity
public class Order {
    private String externalId;      // 直接使用外部字段名
    private BigDecimal totalAmount; // 直接使用外部字段名
    private String customerId;     // 直接使用外部字段名
}
```

**正确代码示例**:
```java
// 建立防腐层，隔离外部依赖
@Service
public class OrderService {

    @Autowired
    private AntiCorruptionLayer antiCorruptionLayer;

    public void processOrder(String externalOrderData) {
        // 通过防腐层转换外部数据为内部领域对象
        Order order = antiCorruptionLayer.translateToOrder(externalOrderData);

        if (order.getStatus() == OrderStatus.PAID) {
            // 业务逻辑使用内部领域对象，稳定可靠
            processPaidOrder(order);
        }
    }
}

// 防腐层负责数据转换
@Component
public class AntiCorruptionLayer {

    @Autowired
    private ThirdPartyApiClient apiClient;

    public Order translateToOrder(String externalOrderData) {
        ThirdPartyOrderDTO externalOrder = parseExternalData(externalOrderData);

        return Order.builder()
                .id(generateInternalId())
                .amount(externalOrder.getTotalAmount())
                .userId(externalOrder.getCustomerId())
                .status(mapExternalStatus(externalOrder.getStatus()))
                .createdTime(externalOrder.getCreateTime())
                .build();
    }

    private OrderStatus mapExternalStatus(String externalStatus) {
        switch (externalStatus) {
            case "PAID": return OrderStatus.PAID;
            case "PENDING": return OrderStatus.PENDING;
            default: return OrderStatus.UNKNOWN;
        }
    }
}

// 内部领域对象，使用DDD规范
@Entity
public class Order {
    @Id
    private Long id;              // 内部ID
    private BigDecimal amount;    // 内部字段名
    private Long userId;          // 内部字段名
    private OrderStatus status;   // 内部枚举
    private LocalDateTime createdTime;
}
```

### 17. 逻辑剥离，service层不能操作dao层，需要repo
**问题描述**: Service层直接操作DAO层，缺乏Repository层
**问题分析**: 业务逻辑与数据访问逻辑耦合，违反分层架构
**潜在风险**: 代码难以测试和维护，职责不清
**解决方案**: 引入Repository层，Service层通过Repository接口操作数据

**错误代码示例**:
```java
// Service层直接操作DAO，职责混乱
@Service
public class UserService {

    @Autowired
    private UserDao userDao;  // 直接注入DAO

    @Autowired
    private OrderDao orderDao; // 直接注入另一个DAO

    public UserVO getUserWithOrders(Long userId) {
        // Service层直接处理数据库查询逻辑
        User user = userDao.findById(userId);

        // 复杂的业务逻辑混在数据访问中
        List<Order> orders = orderDao.findByUserIdAndStatus(userId, OrderStatus.PAID);

        // 数据转换逻辑也在Service中
        List<OrderVO> orderVOs = orders.stream()
                .map(order -> {
                    OrderVO vo = new OrderVO();
                    vo.setId(order.getId());
                    vo.setAmount(order.getAmount());
                    vo.setCreateTime(order.getCreateTime());
                    return vo;
                })
                .collect(Collectors.toList());

        UserVO userVO = new UserVO();
        userVO.setId(user.getId());
        userVO.setName(user.getName());
        userVO.setOrders(orderVOs);

        return userVO;
    }
}
```

**正确代码示例**:
```java
// Repository层封装数据访问逻辑
@Repository
public class UserRepository {

    @Autowired
    private UserDao userDao;

    public Optional<User> findById(Long userId) {
        return Optional.ofNullable(userDao.findById(userId));
    }

    public List<User> findActiveUsers() {
        return userDao.findByStatus(UserStatus.ACTIVE);
    }
}

@Repository
public class OrderRepository {

    @Autowired
    private OrderDao orderDao;

    public List<Order> findPaidOrdersByUserId(Long userId) {
        return orderDao.findByUserIdAndStatus(userId, OrderStatus.PAID);
    }
}

// Service层只关注业务逻辑
@Service
public class UserService {

    @Autowired
    private UserRepository userRepository;

    @Autowired
    private OrderRepository orderRepository;

    @Autowired
    private UserAssembler userAssembler;  // 数据转换组件

    public Optional<UserVO> getUserWithOrders(Long userId) {
        // 通过Repository获取领域对象
        Optional<User> userOpt = userRepository.findById(userId);
        if (!userOpt.isPresent()) {
            return Optional.empty();
        }

        User user = userOpt.get();

        // 获取用户订单（业务逻辑）
        List<Order> paidOrders = orderRepository.findPaidOrdersByUserId(userId);

        // 使用Assembler进行数据转换
        return Optional.of(userAssembler.toUserVO(user, paidOrders));
    }
}

// 数据转换组件
@Component
public class UserAssembler {

    public UserVO toUserVO(User user, List<Order> orders) {
        List<OrderVO> orderVOs = orders.stream()
                .map(this::toOrderVO)
                .collect(Collectors.toList());

        return UserVO.builder()
                .id(user.getId())
                .name(user.getName())
                .orders(orderVOs)
                .build();
    }

    private OrderVO toOrderVO(Order order) {
        return OrderVO.builder()
                .id(order.getId())
                .amount(order.getAmount())
                .createTime(order.getCreateTime())
                .build();
    }
}
```

### 24. 多数用到分页时，应当组件化，避免单独开发
**问题描述**: 各模块重复实现分页逻辑
**问题分析**: 分页参数处理、SQL组装逻辑重复
**潜在风险**: 代码重复，维护困难，分页行为不一致
**解决方案**: 建立统一的分页组件，标准化分页接口

**错误代码示例**:

```java
@Service
public class UserService {
```

**正确代码示例**:
```java
// 统一的分页请求对象
@Data
public class PageRequest {
    private int pageNum = 1;
    private int pageSize = 10;
    private String sortField;
    private String sortDirection = "DESC";

    public int getOffset() {
        return (pageNum - 1) * pageSize;
    }
}

// 统一的分页响应对象
@Data
public class PageResult<T> {
    private List<T> data;
    private int pageNum;
    private int pageSize;
    private long total;
    private int totalPages;
    private boolean hasNext;
    private boolean hasPrevious;

    public PageResult(List<T> data, int pageNum, int pageSize, long total) {
        this.data = data;
        this.pageNum = pageNum;
        this.pageSize = pageSize;
        this.total = total;
        this.totalPages = (int) Math.ceil((double) total / pageSize);
        this.hasNext = pageNum < totalPages;
        this.hasPrevious = pageNum > 1;
    }
}

// 统一的分页组件
@Component
public class PageHelper {

    @Autowired
    private JdbcTemplate jdbcTemplate;

    public <T> PageResult<T> queryPage(String sql, Object[] params,
            PageRequest pageRequest, RowMapper<T> rowMapper) {

        // 构建分页SQL
        String pageSql = buildPageSql(sql, pageRequest);
        Object[] pageParams = buildPageParams(params, pageRequest);

        // 查询数据
        List<T> data = jdbcTemplate.query(pageSql, pageParams, rowMapper);

        // 查询总数
        String countSql = buildCountSql(sql);
        Long total = jdbcTemplate.queryForObject(countSql, params, Long.class);

        return new PageResult<>(data, pageRequest.getPageNum(),
                              pageRequest.getPageSize(), total);
    }

    private String buildPageSql(String sql, PageRequest pageRequest) {
        StringBuilder sb = new StringBuilder(sql);
        if (StringUtils.isNotBlank(pageRequest.getSortField())) {
            sb.append(" ORDER BY ").append(pageRequest.getSortField())
              .append(" ").append(pageRequest.getSortDirection());
        }
        sb.append(" LIMIT ? OFFSET ?");
        return sb.toString();
    }

    private Object[] buildPageParams(Object[] params, PageRequest pageRequest) {
        Object[] pageParams = new Object[params.length + 2];
        System.arraycopy(params, 0, pageParams, 0, params.length);
        pageParams[params.length] = pageRequest.getPageSize();
        pageParams[params.length + 1] = pageRequest.getOffset();
        return pageParams;
```

```java
// 正确的锁使用，设置超时时间
public class InventoryService {

    private final Lock lock = new ReentrantLock();
    private static final long LOCK_TIMEOUT = 5; // 5秒超时

    public void updateInventory(Long productId, int quantity) {
        boolean locked = false;
        try {
            // 设置超时时间，避免永久阻塞
            locked = lock.tryLock(LOCK_TIMEOUT, TimeUnit.SECONDS);
            if (!locked) {
                throw new RuntimeException("Failed to acquire lock within " + LOCK_TIMEOUT + " seconds");
            }

            // 业务逻辑
            Product product = productDao.findById(productId);
            if (product.getStock() + quantity < 0) {
                throw new IllegalArgumentException("Insufficient stock");
            }
            product.setStock(product.getStock() + quantity);
            productDao.update(product);

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("Lock acquisition interrupted", e);
        } finally {
            if (locked) {
                lock.unlock();
            }
        }
    }

    // 使用try-with-resources模式的锁管理
    public void transferInventory(Long fromProductId, Long toProductId, int quantity) {
        try (AutoCloseableLock autoLock = new AutoCloseableLock(lock, LOCK_TIMEOUT)) {
            // 自动获取锁，方法结束时自动释放
            updateInventory(fromProductId, -quantity);
            updateInventory(toProductId, quantity);
        }
    }
}

// 可自动关闭的锁包装器
public class AutoCloseableLock implements AutoCloseable {

    private final Lock lock;
    private final boolean locked;

    public AutoCloseableLock(Lock lock, long timeoutSeconds) {
        this.lock = lock;
        boolean acquired = false;
        try {
            acquired = lock.tryLock(timeoutSeconds, TimeUnit.SECONDS);
            if (!acquired) {
                throw new RuntimeException("Failed to acquire lock within " + timeoutSeconds + " seconds");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("Lock acquisition interrupted", e);
        }
        this.locked = acquired;
    }

    @Override
    public void close() {
        if (locked) {
            lock.unlock();
        }
    }
}

// 读写锁的使用示例
public class ProductCache {

    private final ReadWriteLock rwLock = new ReentrantReadWriteLock();
    private final Lock readLock = rwLock.readLock();
    private final Lock writeLock = rwLock.writeLock();

    private final Map<Long, Product> cache = new ConcurrentHashMap<>();

    public Product getProduct(Long productId) {
        // 读锁可以并发
        try {
            if (readLock.tryLock(2, TimeUnit.SECONDS)) {
                Product product = cache.get(productId);
                if (product == null) {
                    // 缓存未命中，需要写锁
                    readLock.unlock();
                    return loadAndCache(productId);
                }
                return product;
            } else {
                throw new RuntimeException("Failed to acquire read lock");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("Read lock interrupted", e);
        } finally {
            readLock.unlock();
        }
    }

    private Product loadAndCache(Long productId) {
        // 写锁独占
        try {
            if (writeLock.tryLock(5, TimeUnit.SECONDS)) {
                Product product = productDao.findById(productId);
                cache.put(productId, product);
                return product;
            } else {
                throw new RuntimeException("Failed to acquire write lock");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new RuntimeException("Write lock interrupted", e);
        } finally {
            writeLock.unlock();
        }
    }
}
```

```java
// 方案1：传递Class<T>参数保留类型信息
public class DeepCopyUtil {

    public static <T> List<T> deepCopyList(List<T> original, Class<T> elementType) {
        List<T> copy = new ArrayList<>();

        for (T item : original) {
            if (item instanceof Cloneable) {
                try {
                    @SuppressWarnings("unchecked")
                    T cloned = (T) item.getClass().getMethod("clone").invoke(item);
                    copy.add(cloned);
                } catch (Exception e) {
                    throw new RuntimeException("Clone failed for " + elementType.getName(), e);
                }
            } else {
                // 对于不可克隆的对象，可以使用序列化等方式
                copy.add(deepCopyBySerialization(item, elementType));
            }
        }

        return copy;
    }

    @SuppressWarnings("unchecked")
    private static <T> T deepCopyBySerialization(T original, Class<T> type) {
        try {
            ByteArrayOutputStream baos = new ByteArrayOutputStream();
            ObjectOutputStream oos = new ObjectOutputStream(baos);
            oos.writeObject(original);

            ByteArrayInputStream bais = new ByteArrayInputStream(baos.toByteArray());
            ObjectInputStream ois = new ObjectInputStream(bais);
            return (T) ois.readObject();
        } catch (Exception e) {
            throw new RuntimeException("Serialization deep copy failed", e);
        }
    }
}
```

```java
@Configuration
public class ThreadPoolConfig {

    @Bean
    public ThreadPoolExecutor taskExecutor() {
        // 根据CPU核心数和任务类型配置
        int corePoolSize = Runtime.getRuntime().availableProcessors();
        int maxPoolSize = corePoolSize * 2;
        int queueCapacity = 1000;  // 有界队列

        return new ThreadPoolExecutor(
                corePoolSize,      // 合理的核心线程数
                maxPoolSize,       // 合理的最大线程数
                60L,              // 线程空闲存活时间
                TimeUnit.SECONDS,
                new ArrayBlockingQueue<>(queueCapacity),  // 有界队列
                new ThreadFactory() {
                    private final AtomicInteger threadNumber = new AtomicInteger(1);

                    @Override
                    public Thread newThread(Runnable r) {
                        Thread t = new Thread(r, "task-executor-" + threadNumber.getAndIncrement());
                        t.setDaemon(false);
                        t.setPriority(Thread.NORM_PRIORITY);
                        return t;
                    }
                },
                new RejectedExecutionHandler() {
                    @Override
                    public void rejectedExecution(Runnable r, ThreadPoolExecutor executor) {
                        // 拒绝策略：记录日志并抛出异常
                        log.error("Task rejected, pool size: {}, active: {}, queue size: {}",
                                executor.getPoolSize(),
                                executor.getActiveCount(),
                                executor.getQueue().size());
                        throw new RejectedExecutionException("Task rejected due to thread pool overload");
                    }
                }
        );

    @Bean

                maxPoolSize,
```

```java
public class TaskScheduler {

    public void executeWithTimeout(Runnable task, long timeoutMs, int maxIterations) {
        long startTime = System.currentTimeMillis();
        int iterationCount = 0;

        while (iterationCount < maxIterations &&
               (System.currentTimeMillis() - startTime) < timeoutMs &&
               !Thread.currentThread().isInterrupted()) {

            try {
                task.run();
                iterationCount++;

                // 每次执行后短暂休眠
                Thread.sleep(10);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            } catch (Exception e) {
                log.warn("Task execution failed, iteration: " + iterationCount, e);
                // 继续下一次迭代
            }
        }

        if (iterationCount >= maxIterations) {
            log.warn("Task reached maximum iterations: " + maxIterations);
        }

        if ((System.currentTimeMillis() - startTime) >= timeoutMs) {
            log.warn("Task execution timed out after " + timeoutMs + "ms");
        }
    }
```

```java
    private final Set<String> allowedExtensions;

    public SecureFileService(@Value("${app.file.base-dir:/app/files}") String baseDir,
                           @Value("${app.file.max-size:10485760}") long maxFileSize) {
        this.baseDirectory = Paths.get(baseDir).toAbsolutePath().normalize();
        this.allowedExtensions = Set.of("pdf", "doc", "docx", "xls", "xlsx", "txt", "jpg", "png");
        this.maxFileSize = maxFileSize;

        // 确保基础目录存在
        try {
            Files.createDirectories(this.baseDirectory);
        } catch (IOException e) {
            throw new RuntimeException("Failed to create base directory", e);
        }
    }

    /**
     * 安全的文件下载
     */
    public Optional<FileInfo> getFile(String filename) {
        // 验证文件名
        if (!isValidFilename(filename)) {
            throw new IllegalArgumentException("Invalid filename: " + filename);
        }

        Path filePath = baseDirectory.resolve(filename).toAbsolutePath().normalize();

        // 防止路径遍历攻击：确保文件在允许的目录内
        if (!filePath.startsWith(baseDirectory)) {
            throw new SecurityException("Access denied: path traversal attempt detected");
        }

        if (!Files.exists(filePath) || !Files.isRegularFile(filePath)) {
            return Optional.empty();
        }

        try {
            long fileSize = Files.size(filePath);
            String contentType = Files.probeContentType(filePath);

            return Optional.of(new FileInfo(filePath, fileSize, contentType));
        } catch (IOException e) {
            throw new RuntimeException("Failed to read file info", e);
        }
    }

    /**
     * 安全的文件上传
     */
    public String saveUploadedFile(MultipartFile file, String subdirectory) {
        // 验证文件
        validateFile(file);

        // 验证并规范化子目录
        Path subDir = validateAndNormalizeSubdirectory(subdirectory);

        // 生成安全的文件名
        String safeFilename = generateSafeFilename(file.getOriginalFilename());
        Path targetPath = subDir.resolve(safeFilename);

        // 再次检查最终路径是否在允许范围内
        if (!targetPath.startsWith(baseDirectory)) {
            throw new SecurityException("Invalid target path");
        }

        try {
            // 确保父目录存在
            Files.createDirectories(targetPath.getParent());

            // 保存文件
            Files.copy(file.getInputStream(), targetPath, StandardCopyOption.REPLACE_EXISTING);

            return safeFilename;
        } catch (IOException e) {
            throw new RuntimeException("Failed to save file", e);
        }

     * 验证文件名

    private boolean isValidFilename(String filename) {
        if (filename == null || filename.trim().isEmpty()) {
            return false;
        }

        // 检查文件名长度
        if (filename.length() > 255) {
            return false;
        }

        // 检查是否包含路径遍历字符
        if (filename.contains("..") || filename.contains("/") || filename.contains("\\")) {
            return false;
        }

        // 检查文件扩展名
        String extension = getFileExtension(filename);
        return allowedExtensions.contains(extension.toLowerCase());
    }

    /**
     * 验证文件
     */
    private void validateFile(MultipartFile file) {
        if (file == null || file.isEmpty()) {
            throw new IllegalArgumentException("File is empty");
        }

        if (file.getSize() > maxFileSize) {
            throw new IllegalArgumentException("File size exceeds maximum allowed size");
        }

        String filename = file.getOriginalFilename();
        if (!isValidFilename(filename)) {
            throw new IllegalArgumentException("Invalid file: " + filename);
        }
    }

    /**
     * 验证并规范化子目录
     */
    private Path validateAndNormalizeSubdirectory(String subdirectory) {
        if (subdirectory == null) {
            return baseDirectory;
        }

        // 移除开头和结尾的路径分隔符
        subdirectory = subdirectory.replaceAll("^[/\\\\]+", "").replaceAll("[/\\\\]+$", "");

        if (subdirectory.isEmpty()) {
            return baseDirectory;
        }

        // 检查是否包含路径遍历
        if (subdirectory.contains("..")) {
            throw new SecurityException("Path traversal detected in subdirectory");
        }

        Path subDir = baseDirectory.resolve(subdirectory).toAbsolutePath().normalize();

        // 确保子目录在基础目录内
        if (!subDir.startsWith(baseDirectory)) {
            throw new SecurityException("Subdirectory outside base directory");
        }

        return subDir;
    }

    /**
     * 生成安全的文件名
     */
    private String generateSafeFilename(String originalFilename) {
        String extension = getFileExtension(originalFilename);
        String baseName = originalFilename.substring(0, originalFilename.length() - extension.length() - 1);

        // 清理基础名称，只保留字母数字和部分符号
        baseName = baseName.replaceAll("[^a-zA-Z0-9\\-_]", "_");

        // 添加时间戳防止冲突
        String timestamp = String.valueOf(System.currentTimeMillis());

        return baseName + "_" + timestamp + "." + extension;
    }

    private String getFileExtension(String filename) {
        int lastDotIndex = filename.lastIndexOf('.');
        return lastDotIndex > 0 ? filename.substring(lastDotIndex + 1) : "";
    }
```

```java
// 安全的文件处理服务
@Service
public class SafeFileProcessor {

    private static final long MAX_FILE_SIZE = 100 * 1024 * 1024; // 100MB
    private static final int BUFFER_SIZE = 8192; // 8KB

    /**
     * 分块处理大文件
     */
    public void processLargeFile(MultipartFile file, Consumer<String> lineProcessor) {
        // 预先检查文件大小
        if (file.getSize() > MAX_FILE_SIZE) {
            throw new IllegalArgumentException("File size exceeds maximum allowed size: " + MAX_FILE_SIZE);
        }

        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(file.getInputStream(), StandardCharsets.UTF_8), BUFFER_SIZE)) {

            String line;
            while ((line = reader.readLine()) != null) {
                // 逐行处理，避免一次性加载到内存
                lineProcessor.accept(line);
            }

        } catch (IOException e) {
            throw new RuntimeException("File processing failed", e);
        }
    }

    /**
     * 流式处理文件上传
     */
    public String processFileStreaming(MultipartFile file) {
        validateFile(file);

        try (InputStream inputStream = file.getInputStream()) {
            // 使用有限大小的缓冲区
            byte[] buffer = new byte[BUFFER_SIZE];
            int bytesRead;

            StringBuilder result = new StringBuilder();
            long totalBytes = 0;

            while ((bytesRead = inputStream.read(buffer)) != -1) {
                // 限制总读取大小
                totalBytes += bytesRead;
                if (totalBytes > MAX_FILE_SIZE) {
                    throw new IllegalArgumentException("File content too large");
                }

                // 处理缓冲区数据
                String chunk = new String(buffer, 0, bytesRead, StandardCharsets.UTF_8);
                result.append(processChunk(chunk));
            }

            return result.toString();

        } catch (IOException e) {
            throw new RuntimeException("File processing failed", e);
        }
    }

    /**
     * 下载大文件的分块处理
     */
    public void downloadLargeFile(String url, Path targetPath) throws IOException {
        URL fileUrl = new URL(url);
        try (InputStream inputStream = fileUrl.openStream();
             FileOutputStream outputStream = new FileOutputStream(targetPath.toFile())) {

            byte[] buffer = new byte[BUFFER_SIZE];
            int bytesRead;
            long totalBytes = 0;

            while ((bytesRead = inputStream.read(buffer)) != -1) {
                // 检查总大小限制
                totalBytes += bytesRead;
                if (totalBytes > MAX_FILE_SIZE) {
                    throw new IOException("File too large to download");
                }

                outputStream.write(buffer, 0, bytesRead);
            }
        }
    }

    /**
     * 流式JSON处理
     */
    public void processLargeJson(InputStream jsonStream, Consumer<JsonNode> nodeProcessor) {
        try (JsonParser parser = objectMapper.getFactory().createParser(jsonStream)) {
            JsonToken token;

            while ((token = parser.nextToken()) != null) {
                if (token == JsonToken.START_OBJECT) {
                    JsonNode node = objectMapper.readTree(parser);
                    nodeProcessor.accept(node);
                }
            }

        } catch (IOException e) {
            throw new RuntimeException("JSON processing failed", e);
        }
    }

    private void validateFile(MultipartFile file) {
        if (file == null || file.isEmpty()) {
            throw new IllegalArgumentException("File is empty");
        }

        if (file.getSize() > MAX_FILE_SIZE) {
            throw new IllegalArgumentException("File size exceeds limit: " + file.getSize());
        }

        // 检查文件类型（简单的扩展名检查）
        String filename = file.getOriginalFilename();
        if (filename != null && !isAllowedFileType(filename)) {
            throw new IllegalArgumentException("File type not allowed: " + filename);
        }
    }

    private boolean isAllowedFileType(String filename) {
        String extension = filename.substring(filename.lastIndexOf('.') + 1).toLowerCase();
        return List.of("txt", "csv", "json", "xml").contains(extension);
    }

    private String processChunk(String chunk) {
        // 处理单个数据块的业务逻辑
        return chunk.toUpperCase(); // 示例处理
    }
}

// 安全的HTTP控制器
@RestController
public class SafeUploadController {

    @Autowired
    private SafeFileProcessor fileProcessor;

    private static final long MAX_REQUEST_SIZE = 50 * 1024 * 1024; // 50MB

    @PostMapping("/upload")
    public String uploadFile(@RequestParam("file") MultipartFile file) {
        // 验证文件
        if (file.getSize() > MAX_REQUEST_SIZE) {
            throw new IllegalArgumentException("File too large");
        }

        // 流式处理文件
        StringBuilder result = new StringBuilder();
        fileProcessor.processLargeFile(file, line -> {
            // 逐行处理逻辑
            result.append(processLine(line)).append("\n");
        });

        return "Processed " + file.getSize() + " bytes";
    }

    @PostMapping("/process-stream")
    public StreamingResponseBody processStream(@RequestBody InputStream inputStream) {
        return outputStream -> {
            byte[] buffer = new byte[8192];
            int bytesRead;
            long totalBytes = 0;

            while ((bytesRead = inputStream.read(buffer)) != -1) {
                totalBytes += bytesRead;
                if (totalBytes > MAX_REQUEST_SIZE) {
                    throw new IOException("Request body too large");
                }

                // 处理数据块
                outputStream.write(processBuffer(buffer, bytesRead));
            }

            outputStream.flush();
        };
    }

    private String processLine(String line) {
        // 业务处理逻辑
        return line.trim();
    }

    private byte[] processBuffer(byte[] buffer, int length) {
        // 处理缓冲区数据
        String content = new String(buffer, 0, length, StandardCharsets.UTF_8);
        return content.toUpperCase().getBytes(StandardCharsets.UTF_8);
    }
```

## 七、代码评审最佳实践总结

### 1. 性能优化原则
- 避免在循环中进行IO操作
- 使用批量处理减少网络调用
- 合理配置线程池和连接池
- 考虑算法时间复杂度

### 2. 架构设计原则
- 遵循分层架构，职责分离
- 使用设计模式解决常见问题
- 建立防腐层隔离外部依赖
- 组件化通用功能

### 3. 代码质量原则
- 命名准确、规范
- 避免返回null值
- 正确处理资源关闭
- 消除过期无用代码

### 4. 并发安全原则
- 使用线程安全的集合类
- 设置合理的超时时间
- 避免在遍历时修改集合
- 正确配置线程池参数

### 5. 资源管理原则
- 在合适位置初始化资源
- 正确关闭资源连接
- 使用标准库而非自定义实现
- 统一管理配置信息

### 6. 安全合规原则
- 保护敏感信息不被泄露
- 验证和过滤用户输入
- 限制资源访问范围
- 使用成熟的安全组件

通过这些评审要点，可以有效提高代码的质量、安全性和可维护性。在实际评审过程中，需要结合具体业务场景和系统特点，灵活应用这些原则。
