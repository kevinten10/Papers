## 3. spring transaction

### 传播行为

+ REQUIRED 已有则不创建，无则创建
+ REQUIRES_NEW 一律创建新事务。适合独立事务
+ SUPPORTS 加入当前事务，否则不进行事务。适合查询
+ NOT_SUPPORTED 非事务，若有则挂起。适合批量操作
+ mandatory 必须有事务，否则异常。关键逻辑
+ NEVER 必须非事务，否则异常。不允许事务
+ NESTED 创建嵌套事务。子事务
