# 算法题目精简版

## 题目1：字符串数值提取

**问题**：从字符串中提取所有整数（含负数），返回最大值

**示例**：`'afeag-123fae+023faeb+*098'` → 最大值：98

**思路**：双指针遍历，识别数字和负号，解析整数并更新最大值

**核心代码**：
```java
public static int findMaxNumber(String str) {
    int max = Integer.MIN_VALUE, i = 0, n = str.length();
    while (i < n) {
        if (Character.isDigit(str.charAt(i)) || 
            (str.charAt(i) == '-' && i + 1 < n && Character.isDigit(str.charAt(i + 1)))) {
            int sign = str.charAt(i) == '-' ? -1 : 1;
            if (sign == -1) i++;
            int num = 0;
            while (i < n && Character.isDigit(str.charAt(i))) {
                num = num * 10 + (str.charAt(i++) - '0');
            }
            max = Math.max(max, sign * num);
        } else {
            i++;
        }
    }
    return max;
}
```

**复杂度**：时间 O(n)，空间 O(1)

## 题目2：QPS滑动窗口限速器

**问题**：给定滑动窗口大小 n（秒）、QPS限速值 m、请求时间戳列表，计算被限速的请求数量

**思路**：队列维护窗口内请求，遍历时移除超出窗口的旧请求，判断是否超限

**核心代码**：
```java
public static int getQueuedRequestCount(int windowSize, int qpsLimit, List<Long> requests) {
    if (requests == null || requests.isEmpty()) return 0;
    Collections.sort(requests);
    Queue<Long> window = new LinkedList<>();
    int queued = 0;
    long windowMs = windowSize * 1000L;
    for (long requestTime : requests) {
        while (!window.isEmpty() && requestTime - window.peek() > windowMs) {
            window.poll();
        }
        if (window.size() < qpsLimit) {
            window.offer(requestTime);
        } else {
            queued++;
        }
    }
    return queued;
}
```

**复杂度**：时间 O(n log n)，空间 O(n)
