## 优化计划概述

基于对当前代码结构的分析，我将进行以下五个方面的优化：

---

## 1. 雷达图/工具卡片样式区分（未使用工具）

### 1.1 IDE 类别 - 未使用工具标记
**目标工具**：zed、replit
**实现方案**：
- 在 ToolCard.vue 中添加 `used` 字段判断
- 未使用工具显示不同的背景样式（如：透明度降低、边框虚线、添加"未体验"标签）
- 在 tools.json 中为每个工具添加 `used: true/false` 字段

### 1.2 CLI 类别 - 未使用工具标记
**目标工具**：aider、cline
**实现方案同上**

---

## 2. 大表优化 - 按类别分维度对比

### 2.1 当前问题
GlobalTable.vue 将所有工具放在一个总表中，IDE/CLI/LLM 混在一起，无法有效对比

### 2.2 优化方案
- 将大表拆分为多个 Tab 页签：IDE / CLI / LLM / APP / DESKTOP
- 每个类别使用适合该维度的对比字段：
  - **IDE**：代码补全、Agent能力、重构能力、价格
  - **CLI**：模型支持、免费额度、Git集成、价格
  - **LLM**：上下文长度、推理能力、代码能力、中文支持、价格
- 添加类别特定的筛选器

---

## 3. 智能匹配优化

### 3.1 当前问题
ToolMatcher.vue 匹配逻辑较简单，只有4个步骤

### 3.2 优化方案
- 增加更多匹配维度：
  - 技术栈偏好（前端/后端/全栈）
  - 团队规模（个人/小团队/企业）
  - 隐私要求（云端/本地）
- 优化匹配算法，根据类别特性推荐组合
- 添加"为什么推荐这个"的解释说明
- 支持保存和分享匹配结果

---

## 4. 工作流优化

### 4.1 当前问题
WorkflowSection.vue 只有4个固定工作流

### 4.2 优化方案
- 添加更多场景化工作流：
  - 从零开始创业（MVP开发流）
  - 企业级项目维护（存量代码重构流）
  - 开源项目贡献（协作开发流）
  - 技术调研报告（知识沉淀流）
- 每个工作流添加工具组合推荐
- 添加工作流可视化图表

---

## 5. 攻略优化

### 5.1 当前问题
PricingSection.vue 只有三档套餐推荐

### 5.2 优化方案
- 添加更多实用攻略：
  - 学生/教育优惠申请指南
  - 免费额度最大化使用技巧
  - 多账号管理策略
  - API Key 安全最佳实践
- 添加价格对比计算器
- 添加"你的预算能买什么"交互工具
- 补充更多避坑案例

---

## 实施顺序建议

1. **第一步**：数据层 - 在 tools.json 添加 `used` 字段和更多维度数据
2. **第二步**：组件层 - ToolCard 样式区分、GlobalTable 分维度
3. **第三步**：交互层 - ToolMatcher 优化、WorkflowSection 扩展
4. **第四步**：内容层 - PricingSection 攻略补充

- 更直观的工具区分（已用/未用）
- 更有针对性的类别对比
- 更智能的工具推荐
