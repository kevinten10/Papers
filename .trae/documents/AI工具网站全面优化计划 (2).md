## 优化计划概述

基于对现有代码的分析，我将进行以下五个方面的优化：

---

## 1. 雷达图/工具卡片样式区分

### 目标
为未使用过的工具（Zed、Replit、Aider、Cline）添加视觉区分

### 具体改动
**ToolCard.vue**
- 在 tools.json 中添加 `used` 字段标记使用状态
- 未使用工具显示"未体验"标签
- 未使用工具使用不同的背景色（灰色/半透明）
- 添加悬停提示："此工具尚未亲身体验，信息来自调研"

**数据更新**
```json
{
  "id": "zed",
  "used": false,
  "personal_experience": {
    "rating": 4,
    "source": "调研",
    "insights": "..."
  }
}
```

## 2. 大表按维度拆分

### 目标
将 GlobalTable 从单一总表拆分为分类对比表

### 具体改动
**GlobalTable.vue 重构**
- 创建分类标签页（IDE / CLI / LLM / APP / DESKTOP）
- 每个分类显示该维度特有的对比字段：

**IDE 维度字段：**
- 名称/厂商
- 核心模型
- 代码补全能力
- Agent 能力
- 重构能力
- 价格
- 推荐指数

**CLI 维度字段：**
- 名称/厂商
- 模型支持
- 免费额度
- Git 集成
- 自动化能力
- 价格
- 推荐指数

**LLM 维度字段：**
- 名称/厂商

- 价格
- 推荐指数

## 3. 智能匹配优化

### 目标
增强 ToolMatcher 的匹配逻辑和用户体验

### 具体改动
**ToolMatcher.vue**
- 添加更多匹配维度：
  - 团队规模（个人/小团队/企业）
  - 技术栈偏好（前端/后端/全栈）
  - 隐私要求（本地/云端）
- 优化匹配算法权重
- 添加匹配结果解释（为什么推荐这些工具）
- 添加"不满意？重新匹配"按钮

**匹配结果展示优化**
- 显示匹配度百分比
- 添加工具组合建议（IDE + CLI + LLM）
- 显示预估月成本

---

## 4. 工作流优化

### 目标
增强 WorkflowSection 的实用性和细节

### 具体改动
**WorkflowSection.vue**
- 添加更多工作流场景：
  - 后端服务开发流
  - 前端组件开发流
  - 数据科学分析流
  - DevOps 自动化流
- 每个步骤添加：
  - 推荐工具图标
  - 预计耗时
  - 关键产出物
  - 避坑提示
- 添加工作流可视化图表（Mermaid 或流程图）
- 添加"复制工作流"按钮

## 5. 攻略优化

### 目标
增强 PricingSection 的实用性和深度

### 具体改动
**PricingSection.vue**
- 添加更多档位：
  - 学生党（¥0）
  - 个人开发者（¥50）
  - 专业团队（¥200）

- 每个档位添加：
  - 详细工具组合清单
  - 充值路径指引
