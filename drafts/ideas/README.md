# 💡 Ideas - 想法收集

这里存放原始想法，咕噜会定期优化直到形成完整文章。

## 想法格式

```markdown
# [想法标题]

## 核心观点
[一句话描述你想表达什么]

## 背景/动机
[为什么想写这个？]

## 想要涵盖的点
- 点 1
- 点 2
- 点 3

## 参考资料（可选）
- [相关链接/文章]

## 目标读者（可选）
[谁会感兴趣？]

## 状态
- [ ] 初始想法
- [ ] 补充中
- [ ] 可以开始写作
```

## 工作流程

```
你给想法 → ideas/ 记录 → 每小时优化 → 草稿完成 → 移动到 drafts/
```

## 状态说明

| 状态 | 含义 |
|------|------|

| `growing` | 正在优化中 |
| `ready` | 可以开始写作 |
| `draft` | 已生成草稿 |
